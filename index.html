Runtime & Backend

How LLM calls are routed checking
📦
Keyed calls work without a backend — the browser talks straight to Anthropic, Gemini, Groq, OpenRouter, Mistral, Together, DeepSeek, xAI and Perplexity, all of which send CORS headers. Add a backend only if you want keys to stay server-side or need the shared 1/30s keyless throttle. Deploy files (Dockerfile, render.yaml, fly.toml, railway.json) ship with the project.
🔑
Keys are stored locally in your browser and sent only to the provider you're calling — never to a third party. A Pollinations pollen key removes the 30s throttle entirely.
